## 2. 🔍 도구별 상세 분석 및 장단점

---

### 1위 🏆 HWPX 템플릿 + Python XML 자동 치환
**최종 점수: 9.9 / 10**

* **원리**: 최신 한글 양식인 `.hwpx` 파일은 내부가 XML+ZIP 구조입니다. 서식 XML은 건드리지 않고 매주 바뀌는 텍스트 태그(`{{설교제목}}`, `{{성경본문}}` 등)만 파이썬이 1초 만에 교체합니다.
* **장점**:
  1. **서식 100% 보존**: 표 크기, 글자 가로 확대(장평), 배분 정렬, 폰트, 컬러가 1픽셀도 틀어지지 않습니다.
  2. **윈도우 최적화**: 윈도우에서 스크립트 더블클릭 한 번으로 이번 주 주보 파일이 생성되며, 한글에서 열어 바로 컬러 프린터로 인쇄할 수 있습니다.
  3. **완전 무료**: 별도의 유료 라이브러리 없이 Python 기본 기능으로 구동됩니다.
* **유의점**: 기존 `.hwp` 파일을 처음에 한컴오피스에서 `.hwpx`로 1회 저장해야 합니다.

---

### 2위 🥇 Typst (팁스트 - 초고속 최신 조판 엔진)
**최종 점수: 9.6 / 10**

* **원리**: 마크다운처럼 쉬우면서도 밀리미터 단위로 정밀 조판이 가능한 최신 오픈소스 조판 도구입니다. 윈도우용 단일 실행 파일(`typst.exe`) 하나로 구동됩니다.
* **AI가 완벽 해결하는 한글 고유 기능**:
  - 사용자가 복잡한 팁스트 문법을 배울 필요 없이, **AI 에이전트가 한글 전용 헬퍼 함수를 템플릿에 내장**해 드립니다.
  - **글자 가로 확대(장평)**: `#let 장평(비율, 내용) = box(scale(x: 비율, 내용))`
  - **배분 정렬**: `#let 배분(너비, 텍스트) = { ... }` (너비에 맞춰 글자 간격 자동 균등 배분)
* **장점**:
  1. **0.05초 초고속 컬러 PDF 생성**: 원고 데이터 입력 즉시 고화질 벡터 컬러 PDF가 만들어집니다.
  2. **컬러 프린터 완벽 대응**: A4 2단 접지, 컬러 헤더, 테이블 라인 등이 흐려짐 없이 선명하게 출력됩니다.
  3. **완전 무료 & 오픈소스**: 라이선스 비용이 전혀 없습니다.

---

### 3위 🥈 HTML + CSS 기반 웹 조판 & 브라우저 컬러 인쇄
**최종 점수: 9.3 / 10**

* **원리**: 웹 표준 HTML/CSS로 주보 양식을 만들고, 윈도우 기본 Edge나 Chrome 브라우저에서 인쇄(Ctrl+P)하거나 서버 스크립트로 PDF를 출력합니다.
* **장점**:
  1. **한글 장평 완벽 재현**: CSS의 `transform: scaleX(1.25); display: inline-block;`으로 글자 가로 확대 완벽 지원.
  2. **컬러 프린터 & 웹 주보 동시 해결**: 종이 인쇄용 고품질 출력과 스마트폰 교인용 모바일 웹 주보를 한 번에 자동 생성합니다.
  3. **완전 무료**: 브라우저와 기본 도구만으로 100% 무인화 가능.
* **유의점**: 최초 1회 HTML/CSS 템플릿을 정밀하게 제작해 두어야 합니다.

## 3. 🛠️ Typst 한글 조판 헬퍼 코드 (검증 완료)

AI 에이전트가 템플릿에 포함하여 제공하는 한글 조판 핵심 함수입니다. 사용자는 문법을 몰라도 완벽한 서식을 누릴 수 있습니다.

```typst
#set page(
  paper: "a4",
  flipped: true,            // A4 가로 인쇄 (2단 접지용)
  columns: 2,               // 2단 분할
  margin: (x: 12mm, y: 15mm)
)
#set text(font: "KoPubWorldBatang", size: 10pt, lang: "ko")

// [1] 글자 장평(가로 확대) 함수: scaleX와 동일
#let 장평(비율: 120%, 내용) = box(scale(x: 비율, 내용))

// [2] 배분 정렬 함수: 지정된 너비 안에 글자를 균등 분할
#let 배분(너비: 55pt, 텍스트) = {
  let 글자들 = 텍스트.clusters()
  box(width: 너비, {
    for (i, char) in 글자들.enumerate() {
      if i > 0 { h(1fr) }
      char
    }
  })
}

// [3] 주보 순서 테이블 예시
#table(
  columns: (70pt, 1fr, 80pt),
  stroke: (x, y) => if y == 0 { (bottom: 1.5pt, stroke: rgb("#2a52be")) } else { (bottom: 0.5pt, stroke: luma(200)) },
  
  [#배분(너비: 55pt)[예배부름]], [인도자], [다함께],
  [#배분(너비: 55pt)[찬송]], [*#장평(비율: 115%)[새찬송가 28장]*], [다함께],
  [#배분(너비: 55pt)[성경봉독]], [누가복음 10:25-37], [인도자],
  [#배분(너비: 55pt)[말씀선포]], [*#장평(비율: 125%)[선한 이웃은 누구인가]*], [담임목사],
  [#배분(너비: 55pt)[축도]], [], [담임목사],
)
```

## 4. 🚀 윈도우 매주 3분 완성 실전 워크플로우

```text
[ 설교 원고 / 행사 메모 ]
           │
           ▼ (AI 비서에게 입력)
[ AI: 정형 데이터(YAML/JSON) 자동 생성 ]
           │
           ▼ (윈도우 배치파일 1회 클릭)
[ 템플릿 엔진 (HWPX 또는 Typst) ]
           │
           ▼ (1초 완성)
[ 완성본 HWPX / 고화질 컬러 PDF 생성 ]
           │
           ▼ (즉시 출력)
[ 🖨️ 교회 컬러 프린터 인쇄 ]
```

1. **1단계 (원고 수집)**: 목회서신, 설교 본문, 찬양 곡명, 교회 소식을 복사합니다.
2. **2단계 (AI 정제)**: AI 비서에게 전달하여 이번 주 주보 데이터로 정리합니다.
3. **3단계 (1초 치환)**: 윈도우 바탕화면의 실행 파일(또는 `.bat` 스크립트)을 1회 실행합니다.
4. **4단계 (컬러 인쇄)**: 생성된 HWPX 파일을 열거나 PDF를 클릭하여 컬러 프린터로 바로 인쇄합니다.
