# 보안 및 민감 정보 보호 규칙 (Security Rules)

## 1. 비밀 정보 및 API 키 보호
- `.env`, 개인 계정 토큰, 비밀번호, 서비스 인증 키 등은 절대 저장소에 커밋하지 않습니다.
- 필요한 환경 변수는 `.env.example`에 키 이름만 명시하고 값은 비워둡니다.

## 2. 개인정보(PII) 보호
- 주보 데이터에 포함될 수 있는 교인 연락처, 개인 신상 정보 등은 샘플 데이터(`data/samples/`) 작성 시 반드시 가명(예: 홍길동, 010-0000-0000) 처리합니다.
- 실 데이터(`data/inputs/`, `output/`)는 로컬에서만 처리되도록 `.gitignore`에 등록합니다.
