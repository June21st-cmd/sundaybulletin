# 주보 그래픽 및 사진 조판 스킬 (Format Bulletin Graphics)

본 스킬은 향린교회 주보에 사용되는 모든 그래픽 에셋(표지 대문 사진 및 설명란, 6면 목회마당 전면 포스터, 1면 절기별 로고 세트)의 정확한 배치와 비율 불변식을 전담합니다.

---

## 1. 트리거 조건
- 표지 대문 사진(단일 사진 또는 다중 콜라주 사진)을 삽입하거나 변경할 때
- 표지 사진 아래 설명란(Table 0, Row 5)을 작성 또는 갱신할 때
- 6면 목회마당에 전면 포스터나 홍보 이미지를 배치할 때
- 주보 1면 절기별 로고(심볼, 글씨)의 규격 왜곡 여부를 검증하고 교정할 때

---

## 2. 핵심 불변식 및 조판 규칙

### 가. 표지 콜라주 사진 설명 시각적 순서 불변식 (Z-Order Strict Compliance)
1. **시각적 배치 순서 엄수**:
   - 콜라주 사진 설명은 파일명 알파벳순이나 무작위 나열을 엄격히 금지합니다.
   - 반드시 독자의 시선 흐름에 맞춰 **[상단 좌측 ➔ 상단 중앙/우측 ➔ 하단 좌측 ➔ 하단 우측]** 순서로 차례차례 기입합니다.
   - *예시 (2026-10-25)*:
     * 1행: `연극 선천댁 ╻ 초청 하늘뜻펴기(최형묵 목사) ╻ 심원안병무선생30주기추모행사`
     * 2행: `여신도회서울연합회 정기총회 ╻ 장년신도회 나들이`
2. **동일 행사 중복 기입 금지**:
   - 동일 행사의 사진이 여러 장(`선천댁 (1)`, `선천댁 (2)`) 사용되었더라도, 설명란에는 행사명을 **단 한 번만 단일화**하여 기입합니다.
3. **서식 및 구분자**:
   - 항목 구분선은 가름선(` ╻ `)을 사용합니다 (앞뒤 공백 1칸).
   - 문단 서식: 가운데 정렬, 줄간격 130% (`paraPrIDRef="37"`), 10pt 바탕 Bold (`charPrIDRef="26"`).
   - 2줄 구성 시 셀 높이 `height="4581"`~`6250` 유지.
4. **대문 사진 규격 보존**:
   - 사진 칸 셀: 너비 52,624 × 높이 40,060 (`pos treatAsChar="1"`).
   - 사진 크기: 셀 가용폭에 맞추어 너비 51,000 수준, 원본 가로세로 비율(aspect ratio)을 왜곡 없이 유지.

### 나. 목회마당 전면 셀 배경 조판 불변식 (Cell Background Fill)
1. **단순 그림 첨부 금지**:
   - 6면 목회마당 본문 칸(`width="52411" × height="71036"`)에 이미지를 단순 `<hp:pic>` 개체로 넣으면 상하좌우 여백이 생기거나 밀림이 발생합니다.
2. **셀 배경 그림(`imgBrush mode="TOTAL"`) 지정**:
   - 목회마당 본문 셀(`borderFillIDRef="50"`)의 `borderFill` XML에 직접 `imgBrush`를 지정합니다:
     ```xml
     <hc:fillBrush xmlns:hc="http://www.hancom.co.kr/hwpml/2011/core">
       <hc:imgBrush mode="TOTAL">
         <hc:img binaryItemIDRef="image_pastoral" bright="0" contrast="0" effect="REAL_PIC" alpha="0"/>
       </hc:imgBrush>
     </hc:fillBrush>
     ```
   - `mode="TOTAL"`은 셀 크기에 맞추어 이미지를 전면 꽉 차게 렌더링합니다.
   - 셀 내부는 깨끗한 1개 단일 빈 문단 구조를 유지하여 텍스트나 커서 간섭을 배제합니다.

### 다. 절기별 로고 규격 왜곡 방어 불변식 (Rule 11 Compliance)
로고가 찌그러지거나 납작해지는 현상을 방지하기 위해 절기별 전용 규격을 0.1%의 오차도 없이 엄격히 적용합니다.

| 절기 | (1) 심볼 로고 규격 | (2) 글씨 로고 규격 | 비고 |
| :--- | :---: | :---: | :--- |
| **창조절 / 주현절 (초록색)** | **너비 5,437 × 높이 7,800**<br>(비율 0.697) | **너비 18,018 × 높이 6,200**<br>(비율 2.906) | 성령강림절 규격 혼용 시 28.8% 옆으로 뚱뚱해짐 원천 방지 |
| **성령강림절 (빨간색)** | **너비 7,007 × 높이 7,899** | **너비 20,542 × 높이 6,080** | 빨간색 전용 크기 |

## 3. 실행 및 검증 절차
1. **이미지 수집 및 비율 확인**:
   - 원본 이미지의 가로/세로 해상도와 종횡비를 계산하여 셀 내 배치 크기를 결정합니다.
2. **HWPX BinData 및 content.hpf 등록**:
   - 이미지를 `BinData/`에 복사하고 `Contents/content.hpf` 매니페스트에 올바른 미디어 타입(`image/png` 등)으로 등록합니다.
3. **XML 적용**:
   - 표지 사진: Table 0 Row 4에 `<hp:pic pos treatAsChar="1">` 삽입, Row 5에 시각적 순서대로 설명 기입.
   - 목회마당: `Contents/header.xml`의 `borderFill id="50"`에 `imgBrush mode="TOTAL"` 연결.
4. **무결성 검증**:
   - `linesegarray` 태그를 100% 완전 제거하여 보안 경고를 방지합니다.
   - 절기 로고의 `sz` 및 `curSz`가 창조절(5437×7800, 18018×6200) 규격에 정확히 맞는지 스크립트로 검증합니다.
