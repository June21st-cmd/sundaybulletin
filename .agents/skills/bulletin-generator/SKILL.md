# 주보 생성 전문가 (bulletin-generator)

매주 바뀌는 주보 원고 데이터(예배 순서, 설교 정보, 찬송가, 교회 소식 등)를 읽어 정형 템플릿에 주입하고, 컬러 인쇄용 HWPX 및 초고속 고화질 Typst PDF를 생성합니다.

## ⚠️ 실행 가드
* **주보 조판(HWP/PDF)은 사용자가 명시적으로 요청("주보 작업해", "HWP 만들어줘")할 때만 실행합니다.**
* 단순 원고 입력이나 텍스트 정리 단계에서는 절대 임의로 생성 명령을 먼저 수행하지 않습니다.

## 예전 찬송 규칙
* **명칭 표기 원칙**: 주기도문송은 주보에 입력 및 표기 시 **반드시 "주기도송"**으로 입력합니다.
* **응답 찬송 / 고백송 월별 교체 규칙**:
  * **1, 5, 9월**: 주기도송 (`주기도송(1) 245장`)
  * **3, 7, 11월**: 주기도송 (`주기도송(2) 246장`)
  * **2, 4, 6, 8, 10, 12월**: 신앙고백송 (`국악찬송 254장` / `신앙고백송 254장`)
* **결단 찬송**: 국악찬송 등 지정 곡을 `decision_hymn` 및 `worship_offering_hymn`에 매핑합니다.

## 표지 사진 및 로고 조판 가이드
1. **대문 사진 없을 때**:
   - `image2.png` 파일 삭제 및 `section0.xml` 내 사진 칸(`<cellSz width="52624" height="40060">`)의 `<pic>` 태그 완전 제거.
   - 사진 칸 크기(너비 `52624` × 높이 `40060`)는 절대 수정하지 않고 원형 보존.
   - 사진 설명 칸(`<cellSz width="52624" height="4581">`)은 `╻` 기호 한 줄 문단만 유지 (두 줄 이상 생성 금지).
2. **로고 치환 시 8개 필수 동기화 속성**:
   - `orgSz`: 원본 픽셀 × 75
   - `curSz` & `sz`: 타겟 크기 (촛불 높이 `7,800`, 글씨 높이 `6,200` - 너비는 원본 비율에 맞춰 계산)
   - `rotationInfo`: centerX(target_w / 2), centerY(target_h / 2)
   - `scaMatrix`: e1 = target_w / org_w, e5 = target_h / org_h
   - `imgRect`, `imgClip`, `imgDim`: org_w, org_h에 맞춤
3. **비율 불변 원칙**: 원고량에 맞춰 조절하는 예배 순서(2, 3면) 외 타 페이지의 표 셀 비율 임의 수정 금지.

## 지원 엔진
1. **HWPX 엔진 (`src/hwpx_engine.py`)**: 기존 한글 서식(표, 글자 장평, 배분 정렬)을 100% 보존하며 텍스트 태그 치환.
2. **Typst 엔진 (`src/typst_engine.py`)**: 0.05초 초고속 벡터 컬러 PDF 생성 (A4 2단 가로 인쇄).

## 실행 절차
1. **원고 데이터 준비**: `data/inputs/bulletin_YYYYMMDD.yaml` 작성 또는 AI 정제.
2. **생성 명령 실행**:
   ```bash
   python3 src/main.py --data data/inputs/bulletin_YYYYMMDD.yaml --engine all --output output/
   ```
3. **결과 확인**: `output/` 폴더에 생성된 `.hwpx` 및 `.pdf` 파일 확인.
