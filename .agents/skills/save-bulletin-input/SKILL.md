# 주보 원고 입력 및 저장 스킬 (save-bulletin-input)

사용자가 채팅창에 붙여넣은 주보 메모(설교 제목, 본문, 찬송가, 교회 소식 등)를 분석하여 `input/` 폴더 아래에 깔끔한 원고 파일로 저장합니다.

## ⚠️ 철칙: 주보 작업(HWP/PDF) 자동 실행 금지
- 사용자가 원고를 제공하면 **오직 파일 저장(문서 및 YAML 생성)만 수행**합니다.
- 사용자가 명시적으로 **"주보 만들어줘", "HWP 작업해", "인쇄본 생성해"**라고 지시하기 전에는 HWP/PDF 생성 스크립트나 명령을 절대로 실행하지 않습니다.

## 실행 절차
1. **내용 분석**:
   - 주보 일자(예: 2026-09-13), 교회력/절기, 설교 제목, 본문, 찬송가, 교회 소식, 담당자 등을 추출합니다.
   - **예전 찬송 규칙 준수**: 주기도문송은 주보에 입력할 때 **반드시 "주기도송"**으로 입력합니다.
     * **1, 5, 9월**: `주기도송(1) 245장`
     * **3, 7, 11월**: `주기도송(2) 246장`
     * **2, 4, 6, 8, 10, 12월**: `신앙고백송 254장` (또는 `국악찬송 254장`)
2. **input 폴더에 파일 저장**:
   - 사람이 읽고 편집하기 편한 마크다운 문서: `input/YYYY-MM-DD_주보원고.md`
   - 시스템 연동용 정형 데이터 파일: `input/bulletin_YYYYMMDD.yaml` (및 `data/inputs/bulletin_YYYYMMDD.yaml`)
3. **완료 보고**:
   - 저장된 파일 경로와 요약 내용을 간결하게 보고합니다.
   - 주보 조판(HWP/PDF) 생성을 원하실 때 말씀해 주시면 그때 제작한다고 안내합니다.
