# 배포 브랜치 Push 전 확인 스킬

## 언제 이 스킬을 사용하는가

다음 조건을 만족할 때 이 스킬을 반드시 실행한다:
- 사용자가 `dev` 또는 `main` 브랜치에 **push**를 요청하거나, push를 포함하는 작업을 수행할 때
- 구체적으로: `git push`, `gp`, 또는 "main에 반영해줘", "푸시해줘" 등의 요청

> **예외**: 개인 작업 브랜치(feature/...)로의 push에는 적용하지 않는다.

## 실행 절차

1. **현재 브랜치 확인**: push 대상이 `dev` 또는 `main`인지 확인.
2. **사용자에게 명시적 질문**: "dev/main 브랜치에 push합니다. 계속 진행할까요?"
3. **승인 시**: push 진행
4. **거절 시**: push 중단 및 대기
