# 향린교회 주보 지능형 연속 검토 스킬 (review-bulletin)

## 📌 개요
주보 원고 접수 후 최종 인쇄 전까지 거듭되는 수정 과정(`_v1`, `_v2`, `_v3`...)에서, 오타와 규칙 위반뿐 아니라 직전 주 대비 누락, 일정 불일치, 미확정 항목을 자동으로 점검하는 종합 품질 보증(QA) 스킬입니다.

---

## 🔍 핵심 5대 검토 영역

1. **미완성 항목 문서 내 빨간색 시각화**:
   - 쪽수 미정, 찬양 미정, 담당자 미정 등의 항목은 HWPX 및 PDF에 빨간색(`#FF0000`)으로 표기되어 한눈에 식별 가능.
2. **직전 주 주보 대조 (Cross-Week Validation)**:
   - **예배위원 3주 릴레이**: 지난주 [차주] 예고 ➔ 이번 주 [당주] 일치 여부 전수 대조.
   - **공동관심사 연속성**: 이미 지난 과거 일정 방치 적발 및 지난주 '이후 일정'의 이번 주 승격 여부 점검.
3. **버전 간 변경사항 추적 (Version Diff)**:
   - 직전 버전 대비 추가, 수정, 삭제된 항목 요약 및 의도치 않은 누락(공란화) 경고.
4. **향린 15대 고유 규칙 및 달력 정합성 검증 (`hyanglin-admin` 계승)**:
   - 전화번호 순서(`776-9141, 3806`), 여성 신도회 표기(`청녀, 희녀, 장녀`), 공간 층수(향우실 1층 등), 날짜 및 괄호 요일 일치, 새교우 등록일(주일).
5. **국어 맞춤법 및 문장 부호 점검 (Korean Spelling & Punctuation QA)**:
   - 자주 틀리는 50대 한국어 맞춤법(되/돼, 며칠/몇일, 로서/로써, 봬요/뵈요, -ㄹ게요/-ㄹ께요 등) 자동 교정안 제안.
   - 복붙 실수로 인한 동일 단어 연속 중복 및 겹조사(`을를`, `이가`, `에서에서`) 적발.
   - 소괄호`()`, 대괄호`[]`, 큰따옴표`“”`, 홑화살괄호`〈〉` 등 열리고 닫히지 않은 문장 부호 짝 누락 100% 적발.
   - 교회 고유명사 및 성도 성함 보호(화이트리스트)로 불필요한 오작동 원천 차단.

## 🚀 사용법 및 실행 명령

```bash
# 1. 최신 주보 데이터 단독 검토
python scripts/review_bulletin.py [input/bulletin_YYYYMMDD.yaml]

# 2. 직전 주 주보 및 직전 버전과 대조 검토 (보고서 마크다운 저장 포함)
python scripts/review_bulletin.py input/bulletin_YYYYMMDD.yaml \
  --prev-week input/bulletin_PREVDATE.yaml \
  --prev-version input/bulletin_PREV_VER.yaml \
  --version-label "수정본 v2" \
  --save-report
```

## 📋 검토 결과 확인 기준
- **오류 0건 & 빨간색 미완성 항목 0건**: `🟢 인쇄 가능 수준`
- **확인 요망 항목 존재**: `🟠 보완 필요` ➔ 보고서 제안사항을 바탕으로 사용자 확인 후 수정본 생성
