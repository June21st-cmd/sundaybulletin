# 주보 팩트 및 임의 추정 원천 차단 스킬 (validate-bulletin-facts)

## 📌 개요
주보 제작 과정에서 AI가 원고에 없는 행사(예: 당회록의 울너머겹 등)를 멋대로 소식란에 집어넣거나, 
시간·장소가 불분명할 때 임의로 추정(예: 목회운영위원회를 14:00로 적거나 장소 누락)하여 발생하는 치명적인 오류를 사전에 기계적으로 적발하고 원천 차단하는 품질 보증(QA) 스킬입니다.

---

## 🔍 핵심 3대 검증 기능

### 1. 향린교회 정례 모임 '골든 타임/장소 DB' 교차 검증
* 향린교회의 주요 정례 모임은 매주 또는 매월 일정한 시간과 장소에서 열립니다.
* **불변 기준표**:
  * **목회운영위원회**: 통상 **`16:00, 친교실(5층)`** (2026년 불변 기준)
  * **교육부 월례회**: 통상 **`12:40, 세미나실(4층)`**
  * **전체여신도회 임원 모임**: 통상 **`13:00, 담임목사실(4층)`**
* ⚠️ **규칙**: 모임명이 들어가는데 시간이 `16:00`가 아니거나 장소가 빠져 있으면 즉시 **`ERROR`**를 발생시키고 배포를 중단합니다.

### 2. 원고 출처 격리 감사 (Source Leaking Audit)
* 사용자가 제공한 이번 주 확정 원고 텍스트 파일(`data/inputs/YYYY-MM-DD_주보원고.md`)과 YAML/HWPX를 1:1 대조합니다.
* 외부 회의자료(당회록 PDF 등)에 적힌 장기 계획이 사용자의 명시적 지시 없이 소식란에 추가된 경우 **`WARNING (원고 미언급 항목)`** 경고를 발생시킵니다.

### 3. 인접 항목 복붙 오염(Leaked Value) 감지
* 윗줄 항목의 시간(예: 교육부 14:00)이나 장소를 아랫줄(예: 목운위)로 복사-붙여넣기하여 시간이 오염되는 실수를 자동 탐지합니다.

---

## 🚀 실행 방법

```bash
# 1. 단독 팩트 검증 실행
python scripts/validate_bulletin_facts.py [YAML_PATH] [RAW_INPUT_PATH]

# 예시:
python scripts/validate_bulletin_facts.py data/inputs/bulletin_20260920.yaml data/inputs/2026-09-20_주보원고.md
```

## 📋 검증 기준
* **🔴 ERROR 0건**: 필수 통과 조건 (정례 모임 시간 불일치 시 빌드 차단).
* **🟠 WARNING**: 사용자에게 해당 항목이 이번 주 원고에 명시된 것이 맞는지 즉각 질문하고 확인을 받음.
