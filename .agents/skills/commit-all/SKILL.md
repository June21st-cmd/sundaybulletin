# 전체 커밋 스킬 (commit-all)

현재 작업 트리에 남은 모든 변경 사항을 검토하고, 논리적인 단위별로 묶어 clean 상태가 될 때까지 순차적으로 커밋합니다.

## 규칙

1. `git status`로 변경된 모든 파일 목록을 확인합니다.
2. 서로 연관된 파일들끼리 그룹화합니다 (예: 엔진 로직, 템플릿, 문서, 설정).
3. 각 그룹별로 명시적 `git add <files...>` 후 의미 있는 커밋 메시지로 커밋합니다.
4. 모든 파일이 커밋되어 `working tree clean` 상태가 되었는지 확인합니다.
5. 푸시는 실행하지 않습니다.
